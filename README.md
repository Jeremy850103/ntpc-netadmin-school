# 新北網管小學堂：光纖到班接線大作戰

新北市政府教育局指導、顯赫資訊股份有限公司製作的校園網路管理互動課程。序章 3 關、七章 36 關、知識卡 26 張，場景為光纖到班案完工後的新北校園網路：教室端交換器（Edgecore ECS4125-10PL）、副控點交換器（MikroTik CRS326）、核心光纖交換器（MikroTik CRS518）、既有校端 L3 路由器（Juniper EX3400）、校內測速主機與智慧網管系統。

## 內容

| 章 | 關卡 |
|---|---|
| 序章 | 先問範圍、校園網路全貌、認識你的機房 |
| 第一章 光纖到班（L1） | 第一條線、跟著點位編號走、選對模組、PoE 預算 120 瓦、蓋一棟樓、雙電源與雙上行、報修單：整棟大樓斷線 |
| 第二章 交換器（L2） | 誰是誰、VLAN 區域化、燈亮但很慢、收攏層數、報修單：全校間歇性斷線 |
| 第三章 門牌與路由（L3） | IP 三劍客、棟內還是跨棟、領不到門牌、私接分享器、新舊閘道並存、報修單：IP 設定出包 |
| 第四章 窗口與守門員（L4–L7） | 查號台、只開必要的窗、報修單：Wi-Fi 連上卻不能上網、報修單：只能上學校網站 |
| 第五章 無線教室 | 選對名字選對車道、擺對位置選對頻道、AP 改接教室端、報修單：平板可以電腦不行 |
| 第六章 智慧網管 | 一校一卡、看懂拓樸圖、告警判讀、設定備份與比對、線路測速與雷達、盤點計畫填報、報修單：整校離線但設備都亮 |
| 第七章 斷線大搜查 | SOP 總驗收、回報對的窗口、畢業任務 |

課程中的學校「雲海國小」與其位址、電話均為虛構，位址樣式依新北各校慣例（第二段用途、第三段學校）。

## 產線

```
src/01_head.js      學校參數與換字機制
src/02_devices.js   設備定義（埠位、版面、共用工具）
src/10_ch0.js …     各章關卡資料
src/80_cards.js     知識卡
src/81_road.js      章節、報修單、工具箱
src/90_tail.js      引擎（狀態、繪圖、測試、存檔、分享、終端機、講師總表）
build.py            組裝成單檔 出稿/新北網管小學堂.html（index.html 為同一份）
check.py            守門：語法、關卡完整性、文風禁詞、舊版殘留、全關自動解題
test/play.py        用 playwright 逐關重播解法
```

跑法：`python3 build.py && python3 check.py`。
